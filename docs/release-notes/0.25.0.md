This minor release adds the optional managed FastAPI broker (`streamcast[broker]`)
and `inbox(..., initially_paused=False)`. Existing static APIs and default inbox
startup remain compatible. Persist a caller-owned pause and pass it on restart;
identity/offset validation and strict durable row-and-byte low-water checks run
before reception resumes. No wire or table migration is required.

The managed broker is an opt-in host application. Configure authorization/storage
profiles and fence previous writers; local locks are not distributed leases.
Protect and verify original history before root migration or retirement. Already
migrated/trimmed protected histories remain refused pending reviewed broker-mediated
history support. See docs/BROKER.md.

Both aggregate static/managed comparisons meet the recorded performance budgets.
One adjacent short-run ACK-p99 comparison remains +25.92%; the small uncontrolled
sample establishes neither a worst-run tail nor production capacity. Publication
makes the dependency available; production controller/consumer/host acceptance and
safe root handoff remain separate deployment gates.
